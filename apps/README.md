# Apps

배포·실행하는 제품 애플리케이션을 프론트엔드와 백엔드로 나눕니다.

- [frontend](frontend/README.md): PRD의 가이드 먼저형 웹 UI를 개발할 위치.
- [backend](backend/README.md): 기존 production FastAPI 앱과 미디어 워커.

현재 업로드 먼저형 화면은 [prototypes/hookcut](../prototypes/hookcut/README.md)에 보관합니다. 재사용하는 플래너 API와 제작 도구는 [libraries](../libraries/README.md)에서 관리합니다.
